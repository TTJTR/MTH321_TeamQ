# Project 1 — Polar-Factor Gradient Flow

This is the MTH321 team project for Topic 5 in the Problem Pack. We study the matrix ODE

\[
X'(t) = X(t)\bigl(I-X(t)^\mathsf{T}X(t)\bigr),
\]

and compare numerical methods against its finite-time exact solution. The model, experiments, report, and presentation are in progress.

## Layout

- `code/model.py`: model, benchmark initial matrix, exact solution, and diagnostics.
- `code/solvers.py`: numerical methods and adaptive stepping.
- `code/experiments.py`: convergence, stability, cost, and rank-deficient experiments.
- `code/run_all.py`: planned entry point for reproducing results.
- `code/figures/`: figures generated by the experiments.
- `tests/`: validation checks.
- `report/` and `slides/`: source files for the written report and presentation.

## Environment

Use Python 3.10 or newer. Create a virtual environment and install the course dependencies:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

The course's `environment_setup.pdf` gives additional setup and quick-check instructions. Reproduction commands will be added as the experiments are implemented.
