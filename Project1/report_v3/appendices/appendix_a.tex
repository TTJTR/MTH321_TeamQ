\section{AI Transparency Log}
\label{app:ai_log}

Generative AI was used in this project primarily to summarise and clarify
project tasks, and to assist with checking the completeness of project
files and final deliverables.

AI was also used to support an initial synthesis of the numerical results
reported in Sections~2--4. All numerical values included in the report,
including convergence slopes, stability estimates, computational work
counts, and orthogonality defects, were checked against the existing
numerical experiments and report data. The AI-generated drafts did not
introduce any new numerical results.

In addition, AI was used to compare the report structure with the project
brief and to identify missing final-delivery items, such as the Individual
Contribution Statements (ICS), cover-page information, and appendices.

The numerical methods, implementation, experiments, validation data, and
figures used as evidence in the report remain the team's own project
outputs.
