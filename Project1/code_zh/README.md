# 中文代码版本

从 `Project1/` 运行 `python code_zh/run_all.py`。`model.py` 处理矩阵模型、
Jacobian 和精确解；`solvers.py` 实现三种积分法和步长加倍；
`experiments.py` 生成八张图、六份 CSV 和结果摘要；`run_all.py` 是运行入口。

每张图的用途、对应数据及参数见 [中文总说明](../README_ZH.md)，英文版说明见
[README_EN.md](../README_EN.md)。报告引用的图片保存在
[`../report_v1/figures/`](../report_v1/figures/)。
